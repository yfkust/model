## 19. Weaknesses

| dimension | specific_weakness | consequence | supporting_evidence | feasible_improvement |
|---|---|---|---|---|
| preprocessing | Q1 cleaning/alignment reports no anomaly count, KNN K, window threshold, or alignment rule. | The two final features and 100% metrics cannot be independently reconstructed. | Section 4.2.1. | Publish affected counts and deterministic preprocessing parameters; fit imputers/PCA inside folds. |
| leakage | Q1 feature tests and PCA appear to use the full labeled corpus before CV. | Feature selection and representation may overfit validation folds. | Feature selection precedes section 4.2.5 CV description. | Use a pipeline with fold-local alignment, PCA, screening, and model fitting. |

| model comparison | The assertion that dynamic PSO is best across all corrections conflicts with tables where least squares has equal or better R²/RMSE for several forms. | Optimizer-selection logic is overstated and metric-dependent. | Tables 5.4–5.8. | Predefine a primary metric and compare repeated seeded runs plus runtime. |
| factor analysis | Q3 labels cross-classified raw means/variances as synergistic effects without fitting interaction terms. | Descriptive variation can be mistaken for statistical interaction. | Sections 6.2.3–6.2.4. | Fit a covariate-adjusted factorial/regression model and test explicit interaction coefficients. |
| confounding | Q3 does not control frequency or B_peak distributions across factor groups. | Reported temperature/waveform/material rankings may reflect operating-condition composition. | Q3 inputs and grouped summaries. | Check common support and compare within matched/reweighted frequency×B_peak regions. |

| model suitability | The proposed Conv/Bi-LSTM treats heterogeneous tabular fields as a sequence without defining meaningful order. | Bidirectional context may encode arbitrary column adjacency rather than physics. | Figure 7.6 and 10-D feature definition. | Compare against strong tabular baselines and justify/ablate feature ordering. |
| reproducibility | The appendix's “Bi-LSTM” program defines only three `Conv1d` layers and a dense layer, with `input_size=1033`; no LSTM module appears. | The headline Q4 architecture and metrics cannot be reproduced from supplied code. | Appendix Program 2. | Supply the exact model class, tensor shape/order, checkpoint protocol, and evaluation entry point. |
| split consistency | Main text uses 8:1:1, while appendix preprocessing implements only material-stratified 80/20 train/test. | Validation/test membership and reported metrics are ambiguous. | Section 7.2.3 and Appendix Program 4. | Save and publish one set of train/validation/test indices. |
| robustness | Noise standard deviation 0.1 is not tied to raw/normalized units, clipping, seeds, or repeated draws. | The robustness claim has no physical scale or uncertainty. | Section 7.2.4. | Define perturbation after scaling, use plausible ranges, repeat seeds, and report confidence intervals. |
| optimization formulation | Scalarization claims normalization but gives no normalized equations and optimizes weight `a` as a decision variable. | The optimizer can choose the preference itself; the result does not represent a user-defined trade-off. | Section 8.2.2. | Normalize with fixed reference bounds and sweep externally chosen weights. |
